# Correction to the passive-study probe records and the V03 annotation

Applies to [the 1 pF record](../records/20261121-044750-495011a.md) and
[the revised 2 pF record](../records/20261121-101130-e6a7e3e.md). Both
records stay as published. This note supersedes the statements below.

## Sign of the `cap_cmim` `m=` probe capacitance

The prematch probe computed `C = imag(i(vca))/(2 pi f)`. In ngspice `i(v)` is
the current into the source's positive node, which is the current leaving the
capacitor, so the expression reported the capacitance with the wrong sign.
Re-running the two 6.16 µm `cmim` configurations at 1 MHz with the pinned PDK
gives -115.808 fF with the old expression and +115.808 fF with the corrected
one, for both the `m=2` instance and the explicit pair. The ratio is one in
both cases, so the multiplier check conclusion is unchanged. The published
`m2_f` and `two_f` values in `testbench/prematch.json` (about -1.158e-13 F)
carry the wrong sign; their magnitude is correct. The probe now uses
`-imag(i(v))` and the prematch run fails unless the result is positive and
within 2% of twice the sizing model's 6.16 µm plate.

## V03 `Cblk_in` nominal annotation

The V03 plan entry, and the comment line of `testbench/variants/V03.spice`,
give `Cblk_in` as 1.0055e-09 F. The sizing model gives
`119 x model_c_f(rfcmim, 74.8, 74.8, typ) = 1.000139e-09 F`. Only the comment
and the plan annotation carry the wrong value. The simulated element line
(`w=74.8u l=74.8u m=119`) is unchanged, so the measurements stand. The plan
and deck are hash-bound to the published records and are not rewritten.
`passive.cap_annotation_problems` now checks every capacitor annotation
against the sizing model and lists this one as a known erratum.

## Corner logs

The stored `corners/<id>/*.log` entries of the two records contain the parsed
measure dictionary, not the simulator output. Those records cannot be
re-parsed from them. The parsed values are in each record's `-cells.json.gz`
bundle. Runs recorded after this change store each corner's original log
bytes. Raw simulator logs for the two published runs were not retained.
